# Forjix Consultoria

Landing page estática em HTML, CSS e JavaScript.

## Arquivos

- `index.html`
- `styles.css`
- `script.js`
- `assets/services/` — imagens conceituais dos serviços

## Exemplos visuais

As imagens dos serviços são demonstrações conceituais do tipo de solução que a
Forjix pode desenvolver. Elas não representam clientes ou projetos já entregues.

## Antes de publicar

Edite no `index.html`:

1. Número do WhatsApp:
   - procure por `5500000000000`
   - substitua pelo número completo com DDI + DDD

2. E-mail:
   - procure por `contato@forjix.com.br`
   - substitua pelo seu e-mail real

3. Serviços e textos:
   - personalize conforme o posicionamento comercial da Forjix.

## Publicação

Pode ser publicado diretamente em:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- Hospedagem convencional

Não requer backend.

## Projeto demonstrativo

O sistema funcional de estoque e frente de caixa está em
[`demos/forjix-estoque`](demos/forjix-estoque/README.md). Ele possui API, banco de
dados e instruções próprias de execução.
